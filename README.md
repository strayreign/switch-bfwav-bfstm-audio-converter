<h1 id="PageTitle"><strong>Switch BFSTM &amp; BFWAV Audio Converter</strong></h1>

<p>A simple GUI tool that converts audio files and Big-endian (Wii U) BFWAVs/BFSTMs to Little-endian (Switch) BFWAVs/BFSTMs, ready for mods as simple as a drag and a click.</p>

<p>Also converts Little-endian BFWAVs/BFSTMs to WAVs.<br />
<br />
Supports WAV, MP3, OGG, FLAC, AIF, AIFF, M4A, OPUS, WMA, AAC, BFWAV and BFSTM.<br />
<br />
Includes an audio preview player for quality of life.<br />
<br />
<b>Replaces the need for NW4F WaveConverter, Citric Composer, BCFSTM/BCFWAV Converter, BFSTMConverter, vgmstream, the .dspadpcm CMD cleanup script, and a standalone audio converter. Not bad, eh?</b></p>
